# Examples and runnable scripts

This page lists example scripts and experiments. Add these scripts under `scripts/` if you want runnable versions.

Planned example scripts
-----------------------

- `scripts/build-index.js`: build an index from a folder of text files.
- `scripts/search.js`: query an index from the command line.
- `scripts/benchmark.js`: run recall/latency experiments across parameter sweeps.

Notebook suggestions
--------------------

- `notebooks/benchmark.ipynb`: sample queries, metric plots, heatmaps of ef/M settings.
